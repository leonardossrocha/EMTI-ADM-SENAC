## 🚀 Diretrizes do Nosso Modelo de Aprendizagem

Nossos encontros são estruturados seguindo o modelo de excelência da educação profissional do **SENAC**, focando no desenvolvimento de competências, autonomia e marcas formativas essenciais para o mercado de trabalho:

1.  **Metodologias Ativas:** Trabalhamos com Sala de Aula Invertida, Aprendizagem Baseada em Projetos (PBL) e Estudos de Caso reais.
2.  **Cultura de Dados:** Toda análise estratégica administrativa (como Matrizes SWOT ou mapeamentos de mercado) é validada por meio de dados estatísticos, planilhas eletrônicas e bases oficiais (IBGE/CONCLA/IPPUC).
3.  **Avaliação por Menções:** Nosso foco é o alcance dos indicadores de competência profissionais através do sistema:
    *   **A** - Atendido
    *   **PA** - Parcialmente Atendido
    *   **NA** - Não Atendido
